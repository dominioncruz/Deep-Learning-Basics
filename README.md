### Deep Learning Basics

This repository contains practical exercises completed as part of NVIDIA's Fundamentals of Deep Learning course. The notebooks explore core deep learning concepts through image classification, convolutional neural networks, transfer learning, and natural language processing.

#### Projects
1. MNIST Classification

01_mnist.ipynb

Introduces image classification using the MNIST handwritten-digit dataset.

#### 2. American Sign Language Recognition
02_asl.ipynb
03_asl_cnn.ipynb
04a_asl_augmentation.ipynb
04b_asl_predictions.ipynb

Explores image-based sign-language recognition, CNNs, data augmentation, and model predictions.

#### 3. Transfer Learning
05a_doggy_door.ipynb
05b_presidential_doggy_door.ipynb

Applies pretrained models to image recognition tasks, exploring transfer learning in practice.

#### 4. Natural Language Processing

06_nlp.ipynb

Explores introductory deep learning applications in natural language processing.
